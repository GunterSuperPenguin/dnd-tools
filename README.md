# D&D Tools

**A Garry's Mod addon designed to make playing Dungeons & Dragons easier and more convenient.**

D&D Tools is a Garry's Mod addon focused on improving the tabletop role-playing experience by providing additional in-game tools and interface elements for Dungeons & Dragons sessions.

The goal is to make running and playing D&D sessions in Garry's Mod more comfortable, reduce unnecessary manual work, and help players focus on the adventure.

## Installation

### Manual Installation

1. Download or clone this repository.
2. Locate your Garry's Mod installation directory.
3. Copy the addon folder into:

   ```text
   garrysmod/addons/
   ```

4. Launch Garry's Mod.
5. Start or join a server and check that the addon loads correctly.

Make sure the addon's directory structure is preserved when installing it.

### From Source

Clone the repository:

```bash
git clone https://github.com/GunterSuperPenguin/dnd-tools.git
```

Place the resulting addon directory in your Garry's Mod `garrysmod/addons/` folder.

## Usage

Once installed, D&D Tools provides its implemented features inside Garry's Mod.

The addon is intended for use during Dungeons & Dragons sessions, whether you are organizing a game as a Dungeon Master or participating as a player.

For the exact commands, controls, and available tools, refer to the addon source code and any in-game instructions provided by the current version.
